i.
Root cause — mail-attachment PDF extraction unavailable this run: every property report this run arrives as a PDF attached to an Outlook email. Reading those attachments via the Outlook connector's document-read tool returned only the parent email's metadata (subject/body/attachment list) rather than extracted PDF text, for every attachment tried — including retries with explicit page-range parameters. Yesterday's run (9 Sep) successfully parsed the same report types from the same senders, and this run's SharePoint (file-based) document reads worked normally throughout, so the fault appears scoped specifically to mail-attachment PDF extraction this session, not a change in the source files themselves. An internal alert has been sent to alim@ashleyhotels.net flagging this for investigation.
